# JUBDA
분실물 · 습득물 관리 서비스 (Spring Boot · Android)

## 프로젝트 개요
Spring Boot 서버와 Android 앱을 연동하여  
분실물과 습득물을 등록, 조회, 관리할 수 있는 서비스입니다.  
지도 기반 위치 표시와 이미지 등록 기능을 제공합니다.

## 주요 기능
- ✅ 분실물 / 습득물 게시글 등록 및 조회  
- ✅ Naver Map 기반 위치 표시  
- ✅ 이미지 업로드 및 Glide 표시  
- ✅ LOST / FOUND 상태 관리  

## 기술 스택
- **Back-end** : Java 17, Spring Boot, JPA, MySQL  
- **Android** : Kotlin, Retrofit2, Glide, Naver Map  
- **Tools** : GitHub, SourceTree  

## 담당 역할
- Back-end Development  
- 데이터베이스 설계 및 API 구현  
- Android 앱과의 통신(API 연동)
